Application mobile

La police dans votre poche

  • Bouton « Alerte 177 » : votre position GPS part directement vers la salle de commandement, qui vous rappelle. Une alerte n’est jamais perdue.
  • « Vérifier un policier » : scannez le QR code de la carte professionnelle pour confirmer qu’il s’agit d’un vrai agent.
  • Notifications SMS / WhatsApp à chaque étape de votre dossier.
  • Version légère SMS / USSD pour les téléphones simples et les zones à faible connexion.
